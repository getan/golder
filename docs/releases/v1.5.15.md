# golder v1.5.15

## Git tab: preview without taking the writer's index lock

The embedded terminal dependency is pinned to tuios-mini `v0.10.15`.
Its staged/unstaged preview uses a uniquely owned index snapshot for
`git write-tree`, never the real index. The copy stays beside the original
so split-index bases resolve correctly; split-index writes are disabled for
the copy. Cleanup removes only the owned snapshot and its lock.

This avoids reader/reader and reader/writer index.lock failures when quickly
opening diffs or while an agent stages/commits. Original staged content,
intent-to-add flags, sparse indexes, v4 indexes and linked worktrees retain
Git's own semantics. Empty/unborn repositories do not gain a real index merely
because they were viewed. Corruption, merge conflicts and cancellation remain
errors rather than appearing as a clean tree.

Both the embedded Git tab's background status and golder's agent status bar
disable optional Git locks. Actual writes still obey Git's normal locks:
this release does not remove a user's index.lock or retry a commit/stage/discard.

## Approval notes keep the reason as well as the capabilities

When a call needed network or another capability, note construction previously
replaced the reviewer's explanation with “granted: …”; formatting then hid
that duplicate list. Notes now preserve the first nonblank reviewer reason
and display granted capabilities separately. Only an exact duplicate list is
suppressed, not an explanation that happens to begin with “granted:”.
Risk grades, capability decisions and sandbox routing are unchanged.

## Extensions and existing Skills

`/extensions` is one management surface with separate tool-source and Skill
sections. CLI, MCP stdio/HTTP and legacy RPC have explicit type labels and
their own connection/execution lifecycle; Skills retain progressive loading
and `/skill-name`. Source discovery does not execute third-party code.

The implementation includes public Go types and a legacy plugin SDK, the
official Go MCP SDK, explicit fingerprint-bound trust, session-only versus
remembered admission, controlled child processes, CLI management, and
Prompt/Resource previews that are not sent to the model until the user chooses.
Agent SDK embedders opt in with `agent.WithExtensions()`.

No Node runtime, Feishu functionality, automatic installer, OAuth flow,
sampling/elicitation or MCP server is added. Legacy dynamic slash commands
are listed but not invoked directly around the tool gate. See
[the extension guide](../extensions-usage.md).

## Validation and upgrade

Regression coverage includes a real embedded daemon reading staged/unstaged
diffs concurrently under a held fixture index.lock, plus dependency-level
ordinary, split, sparse, v4, intent-to-add, linked, relative-path and unborn
index cases. The tests compare Git's tree hash and verify real index bytes,
mtime, the lock marker and working files remain unchanged. Negative controls
on tuios-mini `v0.10.14` fail with index.lock errors.

Local build, vet, race tests and Linux arm64 cross-compilation are the release
gates. **Linux preflight: suspended** — no Linux container runtime validation
is claimed. Existing workspace daemons do not hot-reload their binary: restart
the workspace with the new golder version to use its updated Git backend.
