# v1.5.70 — Windows desktop compatibility

- Give the Windows GUI an explicit File → Exit menu, routed through the same
  guarded window-close path as the window close button.
- Serialize Windows file pickers. A close request asks only the dialog owned by
  this window to cancel, then finishes terminal/session shutdown when it returns.
- Add Windows-native regression checks for opening and closing the menu with
  Alt and closing a window while its file picker is open. These run in the
  Windows GUI workflow; a macOS cross-build alone does not exercise them.
- Include earlier local changes since v1.5.69: browser cleanup guidance, improved
  macOS application discovery, notarization documentation and a fix for browser
  graphics leaking across workspaces.

Linux container preflight remains suspended. See the GUI workflow for the
Windows-native test result and actual package publication status.
