# golder v1.5.5

Release date: 2026-10-25.

## Security highlights

- Apply the static hard-deny floor to terminal command input, quoted argv and
  both commands in workspace presets, including in full-access mode.
- Preserve the real tool, cwd and target during review; collect outside-path,
  network and external-host-control capabilities through the existing consent
  gate. Mutating broker calls cannot bypass project trust.
- Start agent-controlled terminal and browser helpers with the actual platform
  sandbox, a scrubbed environment and a private temporary home. Helpers receive
  no multiplexer-control grants. Sandbox setup failure never falls back to bare
  execution.
- Default to agent-owned resources. A new browser uses a fresh profile rather
  than silently adopting an existing login session. External control requires
  `host_control:true` and a one-call authorization; attachment grants no standing
  authority.
- Pin pane/browser/tab identity and page URL before review, refuse retargeting,
  block terminal input into agent approval interfaces, reject unsafe browser URL
  schemes across all entry points, and review screenshot writes and empty-shell
  launches rather than treating them as unconditional local allows.

**Auto mode remains automatic.** The reviewer decides without adding human
approval dialogs. A denial or an isolation requirement that cannot be fulfilled
blocks the call; it does not silently weaken the envelope. Initial project trust
remains separate from per-call review.

Existing agents do not hot-reload these protections. Install the updated binary
and restart the agent to use them. An older daemon that cannot enforce helper
launch grants is rejected rather than retried without those grants.

## Validation

- Native build and `go vet`.
- Full-repository short/race regression, excluding PTY-specific interaction
  cases; focused broker, authorization and trust race suites also run without
  those exclusions.
- Actual macOS sandbox execution: a normal command succeeds with inherited
  token variables removed, while an outside-workspace fixture cannot be read.
- Linux ARM64 cross-compilation.
- Linux container preflight remains suspended; no Linux runtime-CI claim is made.

See [broker permissions](../broker-permissions.md) for capability ceilings and
the explicit external-control contract.
