# v1.5.45 — Discoverable Lark and readable pane-control menus

## Lark is visible before configuration

- `/extensions` now includes a first-party **Lark + Project [MCP package]** row
  when no `mcp:lark` source exists. It reports whether `golder-lark` is installed
  and gives the explicit registration next step.
- Package discovery is data-only. It never downloads `golder-lark`, installs the
  official Lark/Meegle CLIs, edits `config.toml`, grants trust, enables a source,
  starts a process, or begins OAuth.
- Once `mcp:lark` is configured, the package placeholder disappears and the real
  MCP source row shows its disabled/approved/connected/authenticated state and
  tool catalog normally.
- Text and JSON extension inventory expose the same package status. Skills remain
  exclusively under `/skills`; the Lark package is not misrepresented as a Skill.

The reported missing plugin on the development machine had two concrete causes:
the executable on `PATH` was still Golder v1.5.42, and neither `golder-lark` nor
an `[mcp.servers.lark]` source was installed. The new package row makes that state
visible instead of presenting an unexplained empty source list.

## Short, layered pane authorization

- The pane's first-level context menu now contains only the current controller,
  **Agent control…**, and revoke. It no longer repeats a long project/role label
  once for every scope.
- **Agent control…** opens an Agent picker, followed by a scope picker containing
  **Next action** and **This conversation**. Agent labels use the short project
  name and add a role only when it is not the ordinary main role.
- The current scope is a right-hand hint. Transfer confirmation renders **From**
  and **To** on separate rows with a short **Confirm transfer** action, preserving
  the decision on narrow terminals.
- Direct-menu provenance, candidate revalidation, exclusive ownership, one-call
  consumption and queued-input revalidation are unchanged.

## Dependency and validation

Golder depends on tuios-mini v0.10.43 for the layered context menu. Unit and race
coverage includes package discovery without source authority, configured-source
deduplication, text/JSON inventory, nested Agent/scope selection, short status
rows, transfer confirmation and all existing lease safety checks.
