## Workspace highlights

- Files opened from the sidebar use a native preview/editor instead of creating
  a pane. Saving retains edits made during an outstanding write and serializes
  repeated save requests.
- The sidebar's Git navigator reuses the existing review UI for the selected
  file: staged changes compare HEAD with the index, while unstaged changes
  compare the index with the working file.
- Original line/hunk comments, edit, resolve, reload and send remain available.
  A single-file review sends only that file's visible unsent comments, using
  the original daemon store and human-authority checks.
- Requests retain their source session, pane and worktree. Moving focus or
  changing the pane's repository cannot redirect a comment or send operation.
- The browser dependency now has a release tag for the public pane/host APIs
  already used by golder, including graceful shutdown and joined input readers.

## CI follow-up in tuios-mini

- Fix the preview's unused assignment and boolean comparison reported by the
  pinned golangci-lint version; keep Darwin CPU sampling off a deprecated helper.
- Give the document and Git-status test packages the repository's required
  process-wide XDG isolation, fixing the package-isolation audit on Linux CI.
- Remove a mutable global deadline from the daemon idle test, avoiding a race
  with another daemon completing shutdown during the local race suite.

Existing processes do not hot-reload embedded dependencies. Restart golder to
use this binary; restart an existing workspace daemon when it is convenient to
move that daemon onto the updated implementation. Installing the binary does
not stop active workspaces.

Linux container preflight remains suspended. Linux cross-compilation is not a
claim that Linux runtime CI was executed.
