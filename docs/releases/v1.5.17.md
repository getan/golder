# golder v1.5.17

## Reduced SSH workspace rendering

The embedded tuios-mini client uses a per-client reduced rendering profile
for terminals reached through SSH, including a local process launched through
OpenSSH rather than only the built-in SSH server.

- Small plain welcome instead of the block-font logo and decorative box.
- ASCII window/rail/file marks, without Nerd Font dependencies or per-file
  icon colouring; filenames, extensions and Unicode text are retained.
- No cosmetic animation, gradients, UI-painted backgrounds, dimming, hover
  decoration, system meters, custom dock/rail refresh jobs or screen savers.
- A 10 Hz ceiling for background pane-output composition, retaining the input
  response window and the existing latest-state compositor.
- Click/wheel/drag reporting instead of cosmetic all-motion traffic; guest
  applications explicitly requesting all-motion continue to receive it.
- Window/session/workspace controls, scrolling, selection, notifications and
  guest terminal content/colours remain functional. No text-pattern filtering
  or unbounded frame queue is introduced.

The profile does not rewrite saved configuration or apply a server shell's SSH
environment to browser clients. `TUIOS_SSH_FULL_UI=1` provides a full-UI control
for local processes started through OpenSSH.

Controlled real OpenSSH tests with the output link limited to 4 KiB/s reduced
the same interaction from 22,770 to 9,292 received bytes (about 59%). Its pane
counter-stream interval fell from 3,466 to 1,015 bytes, and input echo during
output from 259 to 63 ms. These are isolated fixture measurements, not a claim
that the user's one-minute production stall was reproduced or fully fixed.

See [SSH rendering measurements and field collection](../ssh-workspace-rendering.md).

## Terminal-state recovery on startup failure

Independent TUI and visible workspace capture borrowed terminal attributes
before handing control to the framework and restore them on return, including
early errors after raw mode was entered. A disposable-child FD-pressure test
first reproduced the missing restoration and then passed with the backstop,
on a real PTY and in Linux native execution.

This does not add a second stdin reader, close borrowed files, change signal
handling or blindly reset a parent program's protocol modes. It cannot make
reset bytes cross a broken SSH link or recover from SIGKILL. The separate
Escape-fragmentation investigation remains documented; exit-key semantics
are not silently changed by this release.

## Dependencies and upgrade

Golder uses the new tuios-mini `v0.10.17` tag. kitty-browse remains on its latest
published default-branch tag, `v0.2.3`; unchanged dependencies are not republished.

The dependency also repairs the three retained nightly fuzz findings and the
SSH SHM/workspace-readiness race fixtures; see its [CI investigation and negative
controls](https://github.com/getan/tuios-mini/blob/v0.10.17/docs/CI_2026_10_28.md).

Existing workspace daemons and pane agents do not hot-reload their executable.
Use the new binary and explicitly restart only the affected workspace when it
is safe to do so; do not delete sessions/configuration merely to upgrade.

Full Linux container CI preflight remains suspended. Targeted Linux native
PTY/diagnostic and real OpenSSH tests were explicitly authorized and executed;
they are not presented as a full Linux suite run.

## Verification

Against the published dependency tag with `GOWORK=off`: Golder's full race
suite and the input-library fork's tests passed, as did build, vet, tidy,
formatting and Linux arm64/Windows amd64 cross-builds. The final local race
run took 51 seconds. A clean system-Python PATH was used for the optional
getpass compatibility probe; no tested sandbox permissions were widened.
