# v1.5.79 — Concurrent Lark sessions and provider settings

## Lark multi-session execution

- Run up to four verified Lark operations concurrently per source across GUI,
  TUI and independent host processes. Native payload digests pin the audited
  official CLI v1.0.99; unverified CLIs and Meegle remain conservative.
- Serialize conflicting document/workbook/Base operations without blocking
  unrelated resources. Retain resource leases and capacity until cancelled
  helpers actually exit; never replay an unknown business outcome.
- Keep authorization/reset exclusive and refuse busy maintenance before
  disconnecting a session, so a failed maintenance attempt cannot cancel its
  active requests. Preserve approval, schema, sandbox and private-HOME checks.

## Provider settings and mobile view

- Add GUI Auto protocol selection, the explicit `openai/chat` display name,
  default-model-scoped overrides and saved per-provider endpoints/credentials.
- Include mobile tool-result projection and clearer cancellation/draining
  diagnostics from the commits since v1.5.78.

## Validation

Full local Go race tests, vet, formatting, native build and Linux ARM64
cross-build passed. Official native-payload admission was checked against the
verified release download; concurrency tests use temporary state and local MCP
fixtures, not writes to a real Feishu account.

Linux preflight: suspended. Cross-compilation is not a Linux runtime test.
