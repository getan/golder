# golder v1.5.7

Release date: 2026-10-26.

## Reduced terminal repainting, especially over SSH

- Streamed text/reasoning/tool-argument token estimates accumulate without
  changing the visible spinner. Ticks publish both the count and elapsed time,
  including in reduced-motion mode. Sub-agent elapsed labels use the same clock.
- SSH/reduced-motion mode coalesces body updates every 150ms rather than 50ms.
  Input, approval handling and final results do not wait for this timer.
- Ordinary TUI supports `--no-animations` and `GOLDER_NO_ANIMATIONS=1`;
  `SSH_TTY` or `SSH_CONNECTION` enables reduced motion automatically. The first
  key/paste settles an enabled logo animation without losing the input.
- Approvals replace hidden slash menus without shortening the frame. Queued
  previews and approval shortcut tags fit narrow panels without terminal wraps.
- The real cursor remains available for IME positioning. This reduces changed
  frames rather than forcing synchronized output or permanently hiding the caret.

Local regression probes verify zero frame changes from 100 accounting/text
deltas between ticks and zero output bytes from spaced accounting-only messages
between explicit ticks. These are not remote SSH end-to-end latency measurements.
See [TUI latency diagnostics](../tui-latency.md).

## Terminal report fragments no longer become input

A retained Ultraviolet snapshot under `third_party/ultraviolet` supplies a common
input-decoder patch to golder's workspace client, ordinary TUI and embedded
browser. It handles split mouse reports, CSI/SS3 sequences, OSC color/clipboard
replies, control strings, paste markers and UTF-8, with bounds and recovery.
Fuzzing also found an eight-bit X10 bounds panic and incorrect Win32 source-byte
accounting; both are covered by regressions.

This is a golder-local dependency replacement, not a release of standalone
tuios-mini. Tests include a real workspace shell reader and a real inner golder
composer. See [input framing and limits](../terminal-input.md) and the retained
[patch notes](../../third_party/ultraviolet/GOLDER_PATCHES.md).

## Linux sandbox setup

- `/dev/null` redirections no longer request outside-file write authorization.
  bwrap also handles an explicit exact null grant using its existing sandbox
  device rather than attempting to bind a host device as a regular file.
- The installer checks bubblewrap, reuses an installed `bwrap`, or installs it
  with apt, dnf/yum, pacman, zypper or apk through root/sudo. It explains that
  users may install the required package themselves and rerun the script.
  Running golder itself does not require sudo. Host security policies are not
  weakened by the installer.

## Updating existing processes

Processes do not hot-reload the binary. Re-attach the workspace client after
upgrading, and restart/resume existing inner golder agents to load their new
decoder and display behavior. A daemon need not be stopped solely to replace
its attached client's input decoder. Installing does not stop active workspaces.

Local build, vet, full race tests (including retained decoder tests), renderer
probes and Linux arm64 cross-compilation passed. Linux container preflight
remains suspended; cross-compilation is not a claim of Linux runtime validation.
