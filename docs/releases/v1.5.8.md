# golder v1.5.8

Release date: 2026-10-26.

## One startup and TUI trace

`internal/diagtrace` is now the single diagnostic logger shared by the process
start path and the full-screen TUI. `timing_trace.go` is a thin stage adapter;
there is one file, one clock and one switch:

```sh
GOLDER_TUI_TRACE=/tmp/golder-trace.log golder
```

`GOLDER_STARTUP_TRACE` is an alias, with `GOLDER_TUI_TRACE` taking precedence.
The file is appended, created or tightened to mode `0600`, and initialized at
most once per process. Initialization is idempotent; events after close are
harmless. With no path every instrumentation point is a no-op.

The clock starts at package initialization, before `main`, so `+Nms` values from
startup and the TUI are comparable. Lines carry a stage tag:

| Stage | Coverage |
| --- | --- |
| `diag` | process capabilities, terminal environment whitelist |
| `main` | argument count, flags, cwd, config, redaction, grants, dispatch, exit code |
| `setup` | provider, tool set, memory, plugins, skills, prompt; one-time sandbox runner probe |
| `plugin` | each executable's basename, load result and handshake duration; aggregate count |
| `hooks` | dispatcher size and synchronous `SessionStart` duration |
| `session` | session store, resumed messages, trust, host reporting, hook wiring |
| `tui` | session/model/program phases, input/output, Update/View, git probe |

This covers the previously blind interval: plugin handshakes (10s ceiling),
synchronous `SessionStart` hooks (60s ceiling), the bwrap namespace probe
(about 5s on a blocked host), session resume and the terminal handshake each
now have an explicit event before the first frame.

## Privacy

Events record stages, counts, booleans and durations only. They never contain
prompts, keystrokes, clipboard contents, file paths, environment values,
session IDs or credentials. Plugin discovery records only an executable's
basename so a stalled handshake can be named without exposing its directory.
The terminal environment dump remains a fixed capability whitelist; host
variables are recorded by presence, not value.

## Behavior notes

- TUI `+Nms` values are now process-relative instead of relative to `tui.Run`.
- `tui end` marks the TUI returning; `diag trace end` marks process exit. A
  trace without the latter was killed or crashed.
- An existing trace file's permissions are tightened to `0600`.
- Processes do not hot-reload the binary; restart golder to use this release.

## Validation

Local build, vet, full race tests, Linux arm64 cross-compilation and a real
binary smoke test passed. The smoke trace recorded `main begin` through
`exit code=0` and `diag trace end` in about 41ms for `--version`, with mode
`0600`. Linux container preflight remains suspended; cross-compilation is not a
claim of Linux runtime validation.
