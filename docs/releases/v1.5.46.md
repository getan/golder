# v1.5.46 — Golder GUI: native desktop front-end

## What shipped

`golder-gui` is a new, optional desktop app in the `gui/` directory. It is a
separate command; the existing `golder` CLI, TUI and workspace binaries are
unchanged and do not link MyGo.

```sh
go run ./gui/cmd/golder-gui -cwd /path/to/project
```

The window is a semantic front-end, not a terminal inside a window:

- **Sessions** in the sidebar; new, resume and switch. A writer lock refuses a
  second process on the same session, and a session that has not been persisted
  yet still appears while it is open.
- **Transcript**: streamed Markdown, collapsed thinking, tool cards with bounded
  output, compaction and provider notices, interrupt and error states.
- **Approvals**: consent and trust questions answered inline. Closing the window
  answers every pending question as unanswered, which the gates treat as
  fail-closed.
- **Configuration**: a searchable model picker backed by the provider catalog,
  reasoning level, approval mode and a context gauge, all through the same
  `cli.LiveConfig` and `permissions.State` the slash commands mutate.
- **Actions**: a command palette over the existing `runtime.SlashRegistry`, so
  skills, prompt templates and plugin commands stay reachable without typing.
- **Changes**: Git status plus a unified diff, rendered by MyGo's diff viewer.
- **Workspace**: list existing named workspaces and open one in a terminal
  window running `golder workspace attach`. The daemon, PTYs and VT remain
  tuios-mini's; the GUI does not create a second workspace backend.
- **Browser**: discover live control sockets and show a read-only PNG preview.

## Architecture

```
MyGo native UI (gui/mygoui)
        │ typed commands / ordered events
internal/appsession.Controller (no GUI imports)
        │
run.SetupEnv · runtime.StartRun · run.Gates · session.Store
```

The controller is covered by ordinary unit tests, and the views by MyGo's
headless `ui.NewTester`. Both run in `go test ./gui/...`.

## Compatibility

- GUI and CLI sessions are interchangeable: either can resume the other, and the
  stored model/provider remain history while the resuming process serves with
  its live configuration.
- `go build ./...`, `GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build ./...` and
  the Windows GUI build all pass. `go list -deps ./cmd/golder` contains no MyGo
  package.
- Dependency changes: adds `github.com/egoist/mygo v0.7.4`, which raises
  `github.com/ebitengine/purego` to `v0.11.1`, `golang.org/x/image` to
  `v0.46.0`, and adds `github.com/go-text/typesetting v0.3.5`.

## Known limits

- The tuios workspace is opened as a terminal window running
  `golder workspace attach`, not embedded. Embedding needs a snapshot + raw
  stream protocol shared by tuios's VT and MyGo's Ghostty VT; it is not claimed
  here.
- The browser preview is read-only; interaction stays with the browser tool and
  kitty-browse.
- The GUI packages are not behind a `gui` build tag. They live under `gui/` and
  are not imported by `cmd/golder`, but `go build ./...` does compile them.
