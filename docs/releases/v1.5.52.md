# v1.5.52 — Inline approvals and first-token feedback

## Approval cards belong to the transcript

Pending GUI consent is now rendered inside the scrollable transcript using the
same collapsible pattern as tool calls. A new request opens by default so Deny,
Allow once and Always this session remain immediately available; collapsing it
leaves a concise approval headline. Completed requests disappear from the
transcript.

Approval and verdict markers use a fixed-width, top-aligned gutter so multiline
text no longer shifts the exclamation marker relative to nearby cards.

## Visible work before the first token

After the person submits a prompt, the GUI displays a muted `正在思考…` row while
the active run has not produced assistant text, reasoning, a tool call or an
approval. The row disappears as soon as the first visible item arrives; a
pending approval card replaces it instead of duplicating the state.

These changes are isolated to `gui/mygoui`; the terminal TUI approval and
streaming paths are unchanged.

## Validation

Local validation includes GUI race tests, TUI regression tests, formatting,
build, vet, the full race suite and a CGO-free Linux arm64 cross-build. Linux
container preflight remains suspended by user request.
