# Golder v1.5.95

- Make TUI browser recovery choices visually distinct and navigable with the
  arrow keys. A completed choice no longer leaves the recovery card above the
  composer; keeping a browser paused does not resume it, and a later explicit
  `/browser continue` remains available.
- Handle brief browser screenshot 500 errors as transient preview failures,
  without a red warning flash. Persistent failures remain visible, and a
  successful capture clears the warning. Input errors remain separate from
  screenshot errors; stale frames are never used for pointer input.
- Includes the v1.5.94 Lark authorization improvements and hourly GUI/TUI
  update checks. See [v1.5.94](v1.5.94.md).
