# Golder v1.5.94

## Lark authorization results

- Bundle independently versioned Lark helper **1.5.67**. In GUI Settings, use
  **Update helper**, then review and enable the replacement source.
- Recognize the CLI's `authorization_complete` receipt even when it exits
  non-zero because only some requested permissions were granted. Verify the
  user before reporting partial consent; an old login cannot mask a failed flow.
- Partial consent now reports `AUTH_SCOPES_INCOMPLETE` with a bounded list of
  missing scopes instead of the misleading `AUTH_POLL_FAILED`. Granted
  permissions remain usable; do not repeatedly scan without checking application
  permissions, tenant approval and user consent.
- Scope details are a dismissible result of that authorization attempt, not a
  permanent source error. Routine settings show only a short permissions summary.
- Correct the previous diagnosis: CLI device-code polling uses the requested
  scopes cached at initiation; it does not recompute `--domain all`.

## Hourly GUI and TUI update checks

- Check for updates at startup and every hour while the GUI remains open.
- Background checks update the existing indicator only, with no automatic
  download or installation. Manual checks continue to work.
- Skip checks during another update operation or while an installer is staged;
  stop the monitor on window close.
- TUI checks hourly without stealing focus, interrupting a run, or appending
  repeated transcript notices. A compact composer hint points to `/update`.
- `/update` opens upgrade instructions, session dismissal, or persistent skip
  choices. `/update check` refreshes explicitly. Installation remains an explicit
  action outside the running TUI, using the original installation method.
- GUI and TUI reuse the scheduler and comparison code; TUI skip choices reuse
  startup preferences. Automatic TUI checks honor existing update-check opt-outs.
