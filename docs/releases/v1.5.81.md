# v1.5.81 — Checked browser continuation

## Recover a paused browser with one local decision

- Add clickable **Resume automation / Keep paused** controls to the GUI browser
  drawer and composer, the main TUI's browser card, and the browser pane footer.
  Keyboard focus, Enter/Space, local commands and narrow, previously displayed
  confirmation phrases are supported; Ctrl+G remains an auxiliary shortcut.
- Bind recovery to the exact view, instance epoch and pause generation. Keep
  expiring decisions and bounded receipts, query uncertain results instead of
  resending, and preserve verification and server Retry-After enforcement.
- Continue a still-waiting task with one fresh observation turn under current
  permissions. Never replay an unknown submission or revive a cancelled,
  completed or replaced task. Auto/ask do not require a global mode switch.
- Restore controlled ownership only with private view/runtime proof and current
  environment review. Distinguish launch from attested reuse without weakening
  named-profile consent, read-only, deny, contain or sandbox enforce.
