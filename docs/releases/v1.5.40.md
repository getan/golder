# v1.5.40 — Git history and browser popup layering

## Fixes

- Git history lists now open their selected commit, branch, tag, stash and
  remote details instead of failing with `review-history has no parameter ref`.
  The fix also covers commits selected from the graph and file history.
- Git drawers provide clickable back/close controls, wheel scrolling and
  click-away navigation. Shortcut legends are no longer displayed in the Git
  sidebar, drawers or Git row context menus.
- Rename pane/session/workspace dialogs, Git drawers, context menus and the
  other opaque workspace popups now suppress browser graphics through the
  same visibility gate. A live browser frame cannot paint over an open popup.
- Closing the last popup restores the resident browser picture immediately,
  without needing another page update or a refresh. Screenshot selection and
  dock-only key hints do not unnecessarily hide the browser.
- Cancelled history-detail requests cannot overwrite a newer selection, and
  external repository details retain their original repository target.
- Relative Git index snapshot paths are resolved correctly, and settings
  layout regression tests avoid repeatedly rebuilding identical layouts.

## Dependencies

- `github.com/getan/tuios-mini`: **v0.10.39**.
- `github.com/getan/kitty-browse`: **v0.2.6**, the latest stable tag at release.
  This retains explicit browser proxy routing and the first-frame rendering
  fixes from the previous releases.

## Upgrade

Update Golder using your normal installation method, then restart the workspace
to load the updated embedded terminal engine. Existing running workspaces keep
the old code until restarted.
