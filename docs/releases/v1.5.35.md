# v1.5.35

This is a rollback patch for v1.5.34.

v1.5.34 depended on tuios-mini v0.10.37, whose SSH Kitty-query suppression
broke keyboard-enhancement negotiation and made input unreliable. v0.10.37 is
withdrawn.

v1.5.35 depends on tuios-mini v0.10.38, a rollback patch source-equivalent to
v0.10.36 for the affected code. Normal input is restored. The known SSH `5u`
reply remains documented in the tuios-mini v0.10.38 release note; it is not
being fixed by disabling keyboard enhancements.
