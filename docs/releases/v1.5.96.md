# Golder v1.5.96

## Lark helper 1.5.68

- Expand named Sheets operations for common workbook and cell tasks, including
  sheet deletion with exact-target preflight, host approval and readback.
- Add Drive copy and folder creation, Calendar free/busy and RSVP, Task reopen
  and assignment, and Wiki node copy. Prefer named tools over the CLI fallback.
- Report successful CLI dry-runs as previews rather than submitted writes and
  route all named write and aggregate tools through host policy approval.
- See [Lark wrapper coverage](../lark-wrapper-coverage.md) for details and
  limitations. Real-account acceptance and all upstream operations are not
  implied by the unit tests.

## GUI packages

- Stop building the macOS Intel GUI package. The release continues to provide
  macOS Apple Silicon, Windows and Linux GUI packages. The standalone CLI and
  Lark helper still include macOS Intel builds.
