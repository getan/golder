# v1.5.42 — Shared browser profiles, bounded caches, and one extension runtime

## Browser and development cache hygiene

- The project-default browser profile is persistent outside the checkout and is
  shared by the person and project agents. Separately named profiles retain
  exact first-use consent.
- kitty-browse v0.2.8 disables Chromium component updates and removes only
  regenerable component, HTTP/code/GPU and shader caches after taking the
  profile lock. Cookies, Local Storage, IndexedDB, history and downloads remain.
- Fresh private-mode downloads live under the owner-marked temporary profile,
  so normal close and stale-profile pruning clean one classifiable tree.
- Agent guidance and tuios isolation keep GOPATH, GOMODCACHE and GOCACHE in the
  shared system locations instead of duplicating them inside worktrees.

## Extension architecture

- `internal/extensions` is the single host runtime for CLI manifests, legacy
  RPC and MCP sources. Skills remain a separate instruction catalog shown in
  the same management UI and never grant tool authority.
- The unreachable eager plugin manager, duplicate event notifier and dynamic
  legacy slash-command execution path are removed. Legacy v1 compatibility is
  retained as data-only `internal/pluginwire` types and the public
  `extension/plugin` server SDK.
- `/extensions` is grouped into MCP servers, CLI plugins, Legacy RPC plugins and
  Skills (instructions only); `/mcp`, `/plugin` and `/skills` are filtered views.
- First-party Lark code now lives under `extension/plugins/lark`, alongside the
  public extension contracts rather than in a confusing root `plugins` tree.

## Security and dependencies

- Release builds use Go **1.27.3**, fixing reachable standard-library HTTP/2,
  HTTP/1 CONNECT, TLS, x509 and MIME parsing vulnerabilities present in 1.27.1.
- `golang.org/x/net` is **v0.62.0**, fixing GO-2026-6866 and GO-2026-6860 in
  reachable HTML rendering/parsing paths.
- `github.com/getan/kitty-browse` is **v0.2.8** and
  `github.com/getan/tuios-mini` is **v0.10.40**.
- Exact-toolchain `govulncheck` reports no reachable vulnerabilities after the
  upgrades. The transitive `x/crypto/openpgp` advisory has no fixed version and
  no reachable call path in these repositories.

## Validation and upgrade

Local race tests, build, vet, tidy, module verification, Linux arm64
cross-builds and repository CI pass. Linux container runtime preflight remains
suspended by user request. Upgrade Golder normally and restart running agents or
workspaces so the embedded browser and extension catalogs use the new binaries.
