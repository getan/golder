# Golder 会话内容渲染方案

## 目标和边界

让 GUI 中的助手回复适合阅读代码任务的常见内容：Markdown、表格和任务列表、代码块、diff、图片、SVG、Mermaid 和数学公式。原始会话文本仍是唯一持久化数据，预览是可丢弃的派生结果；无法安全或准确渲染时保留原文或图片替代文字。不要执行任意 HTML、JavaScript、用户代码或通用交互图表，也不要因为收到消息而访问网络。

本方案是 **GUI 交付计划**。TUI 使用另一套渲染器：共享内容解析和纯数据校验不代表终端自动有图形展示能力。后续若支持 TUI，需要单独设计终端图片协议、能力检测、布局、降级和测试；不能假设所有终端支持图片或公式字体。

## 优先级

| 优先级 | 内容 | 状态和验收 |
| --- | --- | --- |
| P0 | Markdown、表格、任务列表、代码及复制、diff | 已有，继续保留流式渲染、选择、复制与失败回退；不因新渲染器而破坏。 |
| P1 | 会话内位图图片 | **已实现**项目内 PNG/JPEG/GIF/WebP/BMP 和嵌入式 data 图片。异步解码、控制编码体积和像素数，不自动请求远程 URL，项目切换不能串图。GIF 只显示首帧。 |
| P2 | 带文字的 SVG 图表 | **部分实现**基础形状、渐变与简单文字标签（包括无变换的组），文字以系统字体近似绘制；复杂文字排版、嵌入图片和滤镜等仍回退源码，不能视为完整 SVG。 |
| P3 | Mermaid | **部分实现**封闭代码块内的简单树形流程图和简单时序图，原生离线绘制；汇合、循环、样式等其他语法回退源码，不是完整 Mermaid。 |
| P4 | 数学公式 | **部分实现**行内和块级 TeX，含分数、平方根、部分希腊字母以及简单上下标表达式；不支持的内容回退文本。复杂上下标仍不能视为完整公式支持。 |

P2、P3 和 P4 缺失的语法不能仅凭底层提供回调就宣称已支持；各阶段可独立交付，未实现项应保持明确的源码回退，不改变原会话内容。

## 离线引擎方向和已发现问题

- 优先 Go 原生及来源可核验的上游 WASM，不要求用户安装浏览器、Node 或 Rust，不默认依赖 `xo/mermaid`。运行时不提供网络和工作区访问；锁定版本和校验，审查许可证及传递依赖。安装包增量、macOS 签名和三平台兼容必须实测。
- P2 候选 `tdewolff/canvas`：源码确认其 SVG 解析器虽处理部分 `<text>`，但会访问系统字体且存在不支持的标签和解析边界，不能不加隔离地声称完整或安全。先构建安全的资源限制、字体策略与真实图表测试，再替换现有保守预览。
- P3 当前先用严格的 Go 原生子集覆盖树形流程图（最多 8 节点）和基本时序图（最多 6 参与者、16 条消息），不接受样式或交互。完整方案候选是由可核验的 `mermaid-rs-renderer` 上游源码产出的 WASM，用 `wazero` 调用；需完成可复现构建、WASM ABI、超时与内存限制，以及输出 SVG 的文字渲染。当前没有引入 WASM 或实现接口。此渲染器不是官方 Mermaid，实现存在差异；只展示经验证的类型，并对其他语法回退源码。
- P4 当前使用 BSD-3-Clause 的 `codeberg.org/go-latex/latex v0.3.0`。它对部分常见数学语法仍不完整，不能称为完整 TeX；该库对上下标节点会 panic，简单脚本表达式如 `x^2`、`x_i`、`x^{12}` 和 `E=mc^2` 使用独立字形组合，复杂上下标回退。使用长度、嵌套和输出尺寸限制，捕获解析 panic，未识别时回退；需更换或扩展渲染器才能完整覆盖复杂公式。

## P1 图片设计

- 只解析独立的 Markdown 图片，不读取普通链接。允许相对当前会话项目目录的路径，以及位于该目录内的绝对路径；拒绝路径穿越、项目外路径和符号链接。使用 `os.Root` 将打开操作限制在项目目录，复核普通文件身份，并限制读取字节数。
- 允许受限的 `data:image/...;base64,...`，校验实际文件格式，不信任扩展名或 MIME 字段。禁止网络 URL、`file:` URL 和其他协议的自动加载，以避免追踪、内网访问或任意文件读取。
- 单个图片限 8 MiB、长宽各不超过 8192 像素、总计不超过 1200 万像素，每条消息最多尝试加载 16 张；先检查图片头再解码。失败时沿用 Markdown 的替代文字。SVG 暂不通过位图路径处理，仍沿用现有 SVG 代码块的保守子集。
- 使用 Markdown 自带的后台加载与视图生命周期内缓存，缓存按消息和项目隔离，不让其他项目的同名路径复用；同一条消息中的文件变更不自动刷新，重新打开会话或产生新消息可重新加载。
- 路径处理和图像校验保持为独立函数，以便后续其他界面复用；不改变 TUI 的展示行为。

## 验证

新增自动化测试覆盖常见图片格式、data URI、相对及绝对项目路径、路径穿越、链接、项目切换、异常格式、过大文件和过大像素。GUI 测试验证异步加载后有真实图像而不是只有标签，图片不可用时仍保留替代文字。继续运行 GUI、会话层测试及跨平台构建；P2–P4 实现时分别增加图像对比、恶意输入和降级测试。
