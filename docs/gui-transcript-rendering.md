# Golder 会话内容渲染方案

## 目标和边界

让 GUI 中的助手回复适合阅读代码任务的常见内容：Markdown、表格和任务列表、代码块、diff、图片、SVG、Mermaid 和数学公式。原始会话文本仍是唯一持久化数据，预览是可丢弃的派生结果；无法安全或准确渲染时保留原文或图片替代文字。不要执行任意 HTML、JavaScript、用户代码或通用交互图表，也不要因为收到消息而访问网络。

本方案是 **GUI 交付计划**。TUI 使用另一套渲染器：共享内容解析和纯数据校验不代表终端自动有图形展示能力。后续若支持 TUI，需要单独设计终端图片协议、能力检测、布局、降级和测试；不能假设所有终端支持图片或公式字体。

## 优先级

| 优先级 | 内容 | 状态和验收 |
| --- | --- | --- |
| P0 | Markdown、表格、任务列表、代码及复制、diff | 已有，继续保留流式渲染、选择、复制与失败回退；不因新渲染器而破坏。 |
| P1 | 会话内位图图片 | **已实现**项目内 PNG/JPEG/GIF/WebP/BMP 和嵌入式 data 图片。异步解码、控制编码体积和像素数，不自动请求远程 URL，项目切换不能串图。GIF 只显示首帧。 |
| P2 | 带文字的 SVG 图表 | 使用源码构建的 `resvg` WASM 预览安全的静态 SVG；支持代码块和项目内 SVG 图片。脚本、外链、嵌入图片、动画、`foreignObject` 等回退源码或替代文字，不宣称支持动态 SVG。 |
| P3 | Mermaid | 使用固定版本的离线 WASM 预览流程图、时序图、类图、状态图和 ER 图；不支持的类型、指令及解析失败回退源码。原有简单原生预览在 WASM 不可用时保留。 |
| P4 | 数学公式 | **部分实现**行内和块级 TeX，含分数、平方根、希腊字母、嵌套上下标以及有限矩阵；不支持的内容回退文本，仍不能视为完整 TeX。 |

不支持的语法保持明确的源码回退，不改变原会话内容；静态 SVG 和 Mermaid 也不承诺与浏览器或官方 Mermaid 像素一致。

## 离线引擎方向和已发现问题

- 优先 Go 原生及来源可核验的上游 WASM，不要求用户安装浏览器、Node 或 Rust，不默认依赖 `xo/mermaid`。运行时不提供网络和工作区访问；锁定版本和校验，审查许可证及传递依赖。安装包增量、macOS 签名和三平台兼容必须实测。
- P2 从 MIT/Apache-2.0 的 `resvg` 0.47.0 源码构建 WASI 模块，不采用 MPL-2.0 的 `@resvg/resvg-wasm` 包。Rust 依赖由 `gui/svgwasm/Cargo.lock` 锁定；发布构建检查许可并附带各依赖的许可证原文。除 MIT/Apache 外，传递依赖含 BSD、Zlib、Unicode 等宽松许可，Golder 自身许可证仍为 MIT。
- P3 的 `mermaid-wasm-renderer` 0.3.1 产物来自 `akashacms/mermaid-wasm-renderer` 固定提交 `cf6338f0e905d02620296ad77f75ec9d59ecd7b8`，构建时和运行时均校验 SHA-256 `00d369c98933d0bac9408d9554cef6521b7e62a4ebfe36d9734502d3e73a0cbf`；该值也与该版本 npm 产物一致。发布构建核对该提交中的模块及依赖锁，对锁定依赖检查许可并附带许可证；这不等于已独立复现该预编译模块。它是非官方重实现，不保证与官方 Mermaid 完全一致。构建时获取产物，运行时不联网。
- 两个模块运行在 `wazero` 解释器中，没有挂载宿主文件系统或网络；限制输入、输出、内存、并发和执行时间。SVG 先检查静态标签与引用，只允许本地片段引用。PNG 预览最多 1280×640；超限或不可安全解析时回退。字体先使用随 Go 提供的字体，必要时从已知系统字体路径选择可覆盖所有标签的字体；没有合适字体时回退而不是静默显示缺字。
- P4 当前使用 BSD-3-Clause 的 `codeberg.org/go-latex/latex v0.3.0`；对于带上下标的公式，使用有深度、节点数、图像尺寸和内存预算的解析与绘制，支持嵌套上下标、分数、平方根及有限矩阵。未知语法与不支持的情况回退源码；该实现不是完整 TeX，布局也不是 TeX 排版引擎。

## P1 图片设计

- 只解析独立的 Markdown 图片，不读取普通链接。允许相对当前会话项目目录的路径，以及位于该目录内的绝对路径；拒绝路径穿越、项目外路径和符号链接。使用 `os.Root` 将打开操作限制在项目目录，复核普通文件身份，并限制读取字节数。
- 允许受限的 `data:image/...;base64,...`，校验实际文件格式，不信任扩展名或 MIME 字段。禁止网络 URL、`file:` URL 和其他协议的自动加载，以避免追踪、内网访问或任意文件读取。
- 单个图片限 8 MiB、长宽各不超过 8192 像素、总计不超过 1200 万像素，每条消息最多尝试加载 16 张；先检查图片头再解码。失败时沿用 Markdown 的替代文字。SVG 图片走同一个静态 SVG 沙箱，SVG 自身另受 512 KiB 输入限制。
- 使用 Markdown 自带的后台加载与视图生命周期内缓存，缓存按消息和项目隔离，不让其他项目的同名路径复用；同一条消息中的文件变更不自动刷新，重新打开会话或产生新消息可重新加载。
- 路径处理和图像校验保持为独立函数，以便后续其他界面复用；不改变 TUI 的展示行为。

## 验证

新增自动化测试覆盖图片格式、路径边界、项目切换、SVG 不安全输入、公式回退及资源限制。发布工作流构建源代码 WASM、收集依赖许可证、校验 Mermaid 产物，并对实际模块运行 SVG、Mermaid 和会话界面测试。两个 WASM 模块压缩后打包，运行时在大小限制内解压；开发构建若未生成 `gui/resources/renderers/svg.wasm.gz` 和 `mermaid.wasm.gz`，保留原生子集及源码回退。用户运行已打包 GUI 无需安装 Rust 或联网。
